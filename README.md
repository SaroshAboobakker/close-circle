# Close Circle

A responsive friend-group app prototype for Sarosh, Hassan, Anthony, and Jamser.

## Preview

The app uses plain HTML, CSS, and JavaScript with no build step. GitHub Pages serves the files publicly.

## Current behavior

- Browse a sample feed, memories, hangout polls, and idea board.
- Create posts, vote in hangout polls, and pitch ideas.
- Changes save in localStorage in the current browser only.

## Privacy and sharing

This is a public prototype, not a private shared service. Anyone can open the Pages website and view its source. There are no user accounts, access controls, shared synchronization, or protected media storage. Do not enter or upload private content. The sample posts and plans are illustrative demo content.

To make a real four-person private space, connect an authenticated backend with server-side authorization and private media storage before enabling group posting.

## Run locally

Open index.html in a browser. No package installation is needed.
